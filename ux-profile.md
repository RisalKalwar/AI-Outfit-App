# UX profile

Aesthetic reference: Apple Native (minimal, iOS-first, generous spacing, one accent)
Accessibility target: WCAG 2.1 AA, 44 px touch targets
Microcopy voice: Utilitarian and minimal, verb-first buttons, no blame in errors
Icon library: inline SVG line icons (Lucide paths, 1.5 stroke)
Banned: gradient text, glows, emoji as icons, looping decorative motion, bouncy easing
Stack: single-file HTML PWA, no build step
Motion: transform and opacity only, 100 / 150 / 200 / 300 ms

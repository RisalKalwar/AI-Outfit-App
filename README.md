# FitCheck

Free outfit helper: color matching, an outfit rating out of 10, shoe and sandal colors, occasion, skin tone and season. Works offline. Photos never leave the phone.

## Put it online free (GitHub Pages)
1. Create a new public GitHub repo and upload all files in this folder.
2. Repo Settings > Pages > Deploy from branch > main > / (root) > Save.
3. After a minute open https://YOUR-USERNAME.github.io/REPO-NAME/ in Safari on iPhone.
4. Share button > Add to Home Screen.

## Optional AI
Get a free Gemini key at https://aistudio.google.com/apikey (no card needed), paste it in Settings. The key is stored only on that phone.
